# Агент по оффлайн-запуску и корректировке моделей

Этот навык превращает Hermes в специализированного менеджера по развертыванию локальных моделей, учитывая ограничения железа пользователя (NVIDIA GTX 1660 6GB VRAM) и структуру дисков.

## 🎯 Цель
Максимально упростить импорт GGUF-моделей в Ollama, гарантируя, что модель поместится в видеопамять и будет работать с приемлемой скоростью.

## ⚙️ Контекст Окружения
- **GPU:** NVIDIA GeForce GTX 1660 (6GB VRAM).
- **Путь к GGUF-файлам:** `D:\MODELS\LLM`
- **Хранилище Ollama:** `D:\OllamaModels` (через junction).
- **Рекомендация по квантованию:** Только Q4_K_M, Q4_0 или FP8 для моделей до 8B параметров. Модели > 8B будут работать крайне медленно из-за CPU-offloading.

## 🛠️ Пошаговый Сценарий Запуска (Workflow)

### 1. Поиск и Анализ (Discovery)
- Просканировать папку `D:\MODELS\LLM` на наличие файлов `.gguf`.
- Проверить название файла на наличие меток квантования (например, `Q4_K_M`). 
- **Предупреждение:** Если модель слишком большая (> 5-6 GB), предупредить пользователя о возможном торможении.

### 2. Регистрация в Ollama (Import)
- Создать временный `Modelfile` в рабочей директории:
  `FROM "D:/MODELS/LLM/название_модели.gguf"`
- Выполнить команду создания:
  `ollama create <название_модели> -f Modelfile`
- Удалить временный `Modelfile`.

### 3. Верификация (Verification)
- Проверить наличие модели в списке: `ollama list`.
- Убедиться, что модель корректно зарегистрирована под именем `<название_модели>`.

### 4 idea. Активация и Корректировка (Activation & Tuning)
- Сообщить пользователю, что модель готова.
- Дать четкую инструкцию по переключению в интерфейсе Hermes:
  `Введите команду /model <название_модели>`
- **Корректировка:** Если пользователь сообщает о медленной работе (lagging), предложить:
    1. Перезагрузить Ollama.
    2. Попробовать модель с более низким квантованием (например, с Q6 на Q4).
    3. Закрыть другие приложения, потребляющие VRAM (браузеры, Figma).

## ⚠️ Критические Ошибки и Решения
- **Пути с пробелами:** Всегда заключать пути в Modelfile в двойные кавычки.
- **OOM (Out of Memory):** Если модель вызывает вылет или работает 1 токен в секунду $\rightarrow$ переходить на модель меньшего размера или более агрессивное квантование.
- **Слэши в Windows:** В Modelfile использовать либо `/` либо `\\`.

## 🏁 Чек-лист Успеха
- [ ] Файл найден в `D:\MODELS\LLM`.
- [ ] `ollama create` завершился без ошибок.
- [ ] Модель видна в `ollama list`.
- [ ] Пользователь переключил модель через `/model`.
